# Обратная связь CoDoc

## Что подключено

- Кнопка «Обратная связь» в шапке рабочей области и внизу главной.
- Никаких автоматических окон, таймеров, повторных напоминаний и обязательных опросов.
- Быстрая оценка 1–5 и одна тема: сервис в целом, шаблоны, данные или генерация.
- «Хочу написать подробнее» открывает вашу [Яндекс Форму](https://forms.yandex.ru/u/6aea2bde49af470247e9dcf9/) внутри окна. Есть ссылка открытия в отдельной вкладке.

## Где хранятся ответы

**Оценки** передаются в счётчик Метрики **114057241** с целью `feedback_rating_submitted`. Параметры: `rating`, `topic`, `surface`. Текст, email, имена, содержимое документов и их идентификаторы в Метрику не передаются.

**Подробные отзывы** отправляются непосредственно в Яндекс Формы. Посмотреть их можно в вашем аккаунте: откройте форму → раздел «Ответы». База данных backend, файлы, localStorage и IndexedDB для отзывов не используются. Неотправленная оценка существует только в памяти открытой страницы.

## Однократная настройка Метрики

В кабинете счётчика создайте JavaScript-цели:

| Идентификатор | Событие |
| --- | --- |
| `feedback_opened` | Пользователь открыл окно |
| `feedback_rating_submitted` | Пользователь отправил оценку |
| `feedback_form_opened` | Пользователь открыл подробную форму |

Это требуется для отображения целей и параметров в отчётах. В отчёте «Параметры событий» выберите `feedback_rating_submitted`, затем `rating` / `topic` / `surface`. Код уже отправляет эти события; цели в вашем аккаунте автоматически не создавались.

Нажатие «Написать подробнее» не считается отправленным текстовым отзывом. У встроенной формы свой интерфейс подтверждения; приложение не выдумывает событие отправки по загрузке iframe.

## Надёжность и приватность

- Внешняя форма не загружается до прямого действия пользователя. Сторонний JS-виджет на все страницы не добавлялся.
- Сообщение «Спасибо» для оценки показывается после callback Метрики. При отсутствии callback за 12 секунд показывается ошибка и возможность повторить; текстовая форма доступна отдельно и при блокировке аналитики.
- Callback Метрики подтверждает выполнение запроса провайдером, но не заменяет проверку отчёта в кабинете. При сетевой неопределённости повторная отправка может дать дубль; Метрика не является транзакционной системой заявок.
- URL формы ограничен HTTPS и официальными доменами Яндекс Форм. Номер документа, текущий URL и referrer в форму не подставляются. Встраивание разрешено в CSP Nginx.
- Окно закрывается крестиком, кликом по фону или Escape. Фокус остаётся в окне и возвращается на кнопку после закрытия. Внутри внешнего iframe Escape может обрабатываться самой формой; крестик остаётся доступным.

## Конфигурация и выкладка

В `.env.production` уже задано:

```dotenv
VITE_FEEDBACK_FORM_URL=https://forms.yandex.ru/u/6aea2bde49af470247e9dcf9/
```

Тот же URL задан по умолчанию в `ticket-infra/Dockerfile`; при необходимости его можно заменить аргументом сборки `VITE_FEEDBACK_FORM_URL`. После изменения переменных пересоберите приложение. В dev-сборке отправка в production-счётчик отключена; полную проверку оценок проводите через `npm run build` и `npm run preview`.

В Яндекс Формах убедитесь, что форма опубликована и доступна всем нужным посетителям. Если нужны уведомления о новых ответах, настройте их в интерфейсе формы. Уведомления, права доступа и вопросы вашей формы приложением не изменялись.

Источники: [встраивание Яндекс Форм](https://yandex.ru/support/forms/ru/publish), [reachGoal и callback](https://yandex.ru/support/metrica/ru/objects/reachgoal), [JavaScript-цели](https://yandex.ru/support/metrica/ru/general/goal-js-event), [параметры событий](https://www.yandex.com/support/metrica/ru/reports/event-params).
